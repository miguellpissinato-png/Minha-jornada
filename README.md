# Minha Jornada

Jogo de estudos para o 2º dia do Enem 2026 (15/11), em pixel art 2D.

- **Acampamento:** dias até a prova, tempo estudado, tópicos concluídos, jornada e escolha de matéria.
- **Estudos:** o esqueleto anda pela trilha com o timer de nuvens no céu; na pausa ele descansa na fogueira.

Cada pessoa tem a própria jornada, salva no navegador do aparelho em que abriu. Não precisa de login.

Arquivo único: `index.html`.
